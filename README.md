## Fala parceiro(a)! Suave?

Meu nome é Gustavo Cintra. Construo software com IA no centro do processo: descrevo o problema, itero rápido com agentes de código e entrego produtos que funcionam.

Não tenho dez anos de estrada nem um portfólio gigante. Tenho velocidade de execução, obsessão por tecnologia e o hábito de colocar no ar o que eu começo. Este repositório mostra **como eu trabalho**, e como sai os softwares que eu desenvolvo.

<br/>

## Como eu construo

| | Etapa | O que acontece |
|:-:|:--|:--|
| **01** | **Ideia** | Defino o problema, quem sofre com ele e qual é o menor produto que resolve. |
| **02** | **Protótipo** | No **Lovable** transformo o briefing em interface funcional em horas. |
| **03** | **Backend** | No **Supabase** entram banco Postgres, autenticação e regras de acesso (RLS). |
| **04** | **Refino** | No **Claude Code** reviso, refatoro, corrijo bugs e evoluo o código direto no repositório. |
| **05** | **Deploy** | Publico, meço o uso e volto para a etapa 01 com dados reais. |
